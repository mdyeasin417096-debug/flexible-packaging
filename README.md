# Flexible Packaging — 15 Screen UI

This version contains the requested 15-screen Flutter UI:
1. Splash
2. Language Selection
3. Login
4. Registration
5. OTP Verification
6. Home / Dashboard
7. Search Jobs
8. Job Listings
9. Job Details
10. Apply for Job
11. My Applications
12. Saved Jobs
13. Notifications
14. Profile
15. Settings

The current build is a UI/demo foundation. Authentication, Firebase, real CV upload, push notifications, and server-side job/application data are not connected yet.
